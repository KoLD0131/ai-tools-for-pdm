# Кто выгуливает Бориса

Учебный micro-MVP для вымышленной компании «Догяндекс». В московском офисе 111 сотрудников и пёс Борис. Общая страница нужна, чтобы Борис не остался без прогулки или еды.

Контракт поведения — [`spec.md`](spec.md). Все имена и значения синтетические.

## Пользователь

Любой сотрудник офиса. Регистрации, авторизации, ролей и личного кабинета нет: страница общая.

## Главный сценарий

Сотрудник открывает страницу, видит текущую дату и пять слотов на сегодня: `09:00`, `11:00`, `13:00`, `15:00`, `17:00`. Выбирает свободный слот, вводит синтетическое ФИО, например «Анна Тестова», и подтверждает запись. Слот становится занятым, в нём видно это ФИО.

Другой сотрудник, например «Илья Примеров», пытается занять тот же слот и получает понятный отказ. Исходная запись не меняется. После обновления страницы или открытия во втором браузере состояние то же: оно хранится в SQLite.

## Дополнительная функция

Карточка «Последнее кормление» показывает время и ФИО того, кто отметил кормление последним. Новая отметка, например от «Ильи Примерова», обновляет карточку. Это не второй сценарий и не второй продукт.

## Границы

В проект входит одна страница, пять слотов только на текущую дату, запись по ФИО, отказ сервера при повторной записи, SQLite и карточка последнего кормления.

Не входит: регистрация, авторизация, корпоративный SSO, роли, справочник 111 сотрудников, отмена и администрирование записей, уведомления, календарь на неделю, история действий, несколько собак, второй MVP, реальные ФИО, секреты, внешние интеграции, обязательный деплой и production-grade инфраструктура. Live-ссылка необязательна и не заменяет скриншоты.

## Фактический запуск

Нужен Node.js 24: SQLite берётся из встроенного модуля `node:sqlite`, отдельные пакеты устанавливать не нужно.

В папке проекта:

```bash
npm start
```

Страница открывается на http://127.0.0.1:3000. Записи и кормление хранятся в `boris.sqlite` рядом с `server.js`. Этот файл не коммитится. Чтобы снова получить пустые слоты, остановите сервер, удалите `boris.sqlite` и снова выполните `npm start`.
