# След итерации: запись через SQLite

## Задача

Подключить страницу к Node.js и хранить слоты и кормление в SQLite. Повторную запись в занятый слот должен отклонять сервер, а не только скрытая кнопка.

## Что изменено

Появились `package.json`, `server.js` и `.gitignore`. `index.html` перестал хранить запись только в памяти страницы и стал запрашивать `/api/state`, `/api/bookings` и `/api/feedings`.

Запись выполняется одним запросом:

```sql
UPDATE walk_slots
SET booked_by = ?, booked_at = ?
WHERE walk_date = ? AND slot_time = ? AND booked_by IS NULL
```

Если строка не изменилась, сервер отвечает `409` и оставляет первое ФИО.
